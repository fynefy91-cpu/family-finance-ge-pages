Family Finance GE

A personal-use utility for organizing household spending records in Actual Budget.

What it does

Family Finance GE helps its operator process bank transaction notification messages stored in designated Google Drive folders and convert supported transactions into entries in a self-managed Actual Budget.

The Google Drive connection is used to read files relevant to this workflow. The utility is not a public banking service and does not request access to bank accounts or banking passwords.

How the integration works

  1. Bank notification messages are saved in designated private Google Drive folders by the account holder's own automation.
  2. When the account holder's Mac wakes up, a locally running program can read those files from Google Drive and interpret eligible transactions in memory.
  3. The resulting entries are sent to the account holder's configured Actual Budget instance. Duplicate checks are used to reduce repeat imports.

Only supported messages are eligible for import. Some kinds of messages, including authentication codes, are deliberately excluded. Some bank integrations may remain inactive pending format validation.

Privacy

Financial source files are not published on this website or in its GitHub repository. For a fuller explanation of data use and retention, see the Privacy Policy.
